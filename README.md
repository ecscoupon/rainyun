# ✅ 雨云服务器基础测评

### 优势

1. **价格低，试错成本小**：新用户首月半价，支持月付，7 天无理由退款；有会员返利、活动优惠券，入门机型十几元 / 月起。
2. **机房线路丰富**：国内宁波 / 宿迁 / 十堰（需备案，部分带高防）；香港、美国洛杉矶免备案节点，BGP/CMIN2/AS4837 线路可选，部分机型大带宽rainycloud...。
3. **上手友好**：面板自研简洁，可一键预装宝塔、1Panel；支持 Linux/Windows，弹性升级 CPU、内存、硬盘，自带监控、快照备份雨云论坛。
4. **游戏云专项**：专门游戏云机型，适合 MC 等联机服，可选高防 IP。

### 短板

1. **定位轻量**：相比阿里云 / 腾讯云，SLA 保障、超大集群稳定性、企业级售后偏弱，**不适合核心生产业务、高并发电商**。
2. **计费坑点**：区分**流量计费、固定带宽、动态计费**，流量突发时按量套餐容易超额扣费；动态计费高负载会额外计费。
3. **国内节点必须备案**，备案流程和大厂一样，不想备案只能选香港 / 海外节点；海外节点存在晚高峰网络波动风险。
4. **硬盘默认 30G 系统盘**，大容量需要额外付费扩容。

# ❓ 雨云服务器常见问题 Q&A

1. **国内节点和海外节点区别？**
国内（宁波、宿迁等）：延迟低，访问稳定，**必须备案**；香港 / 美国：免备案，国内访问晚高峰可能抖动，适合快速上线测试。
2. **流量计费 vs 固定带宽怎么选？**

- 平时流量小、偶尔突发、测试用：流量计费，设置封顶，防止爆账单；
- 长期稳定跑网站 / 游戏服：优先**固定带宽**，费用可控，避免超额扣费；
- 持续高负载游戏服：避开动态计费，防止 CPU 高额附加费用。

3. **要不要加高防 IP？**
个人小博客一般不需要；游戏服、容易被 CC 攻击的业务，再选购高防 IP，价格会上涨。
4. **Windows 还是 Linux？**
建站、跑脚本优先 Linux（内存占用低，2G 足够）；Windows 内存开销大，至少 2G 起步，适合只熟悉远程桌面的小白。
5. **IP 可以单独购买吗？**
可以额外购买独立 IPv4；国内 IP 实名 + 备案，海外 IP 免备案。
6. **数据安全？**
自带快照备份，但**不替代异地备份**，重要业务建议自己额外备份数据。

# 📌 雨云服务器选购建议

### 1. 机房选择

- 国内用户，愿意备案、追求稳定低延迟：**浙江宁波 / 江苏宿迁 BGP**
- 不想备案，国内访问：**香港节点**（优先 BGP 线路，避开单线）
- 面向海外访客：美国洛杉矶

### 2. 配置选型（起步参考）

- 个人博客、静态站、学习环境：**1 核 2G，30G 系统盘，10M 固定带宽 Linux**
- WordPress / 小型动态网站、轻量 API：**2 核 2G~2 核 4G**
- MC 游戏服、多服务部署：**2 核 4G 起步，游戏云机型**
- Windows 系统最低 2G 内存，建议 4G 以上更流畅

### 3. 计费策略优先原则

> 
> 长期业务选**固定带宽**；短期测试、流量波动大选流量计费并设置流量封顶；持续高负载业务**不要选动态计费**。

### 4. 避坑清单

- 国内节点**一定要备案**，未备案域名无法绑定国内 IP；
- 海外节点适合测试，不要用于国内经营性网站；
- 新用户先用优惠月付体验，不要直接一次性多年付；
- 重要数据手动异地备份，不要只依赖服务商快照；
- 线路优先 BGP，单线容易出现某运营商延迟高、丢包。
